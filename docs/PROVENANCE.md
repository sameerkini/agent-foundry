# Provenance and release boundary

The Agent Foundry implementation is newly authored for this reusable harness project. The Fieldnote example reuses its independently authored fictional research-station observations and reports. No financial dataset, recruiting brief, private answer export, previous Git history, credentials or personal chat logs are included.

Dependencies and their versions are recorded in `pyproject.toml` and `uv.lock`; their licenses remain their authors'. No project license has been selected. AI assistance supported implementation, tests, architecture review and documentation.

The publication review inspected the complete local Git history and tracked files for credentials, private runtime records and unrelated assignment materials. The included SQLite database contains only fictional research-station data. The source is a portfolio prototype, with the validation limits recorded in `VALIDATION.md`; publication does not establish hosted-model accuracy or production readiness. No hosted service is deployed by this repository.
