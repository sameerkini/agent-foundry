# Provenance and release boundary

The Agent Foundry implementation is newly authored for this reusable harness project. The Fieldnote example reuses its independently authored fictional research-station observations and reports. No financial dataset, recruiting brief, private answer export, previous Git history, credentials or personal chat logs are included.

Dependencies and their versions are recorded in `pyproject.toml` and `uv.lock`; their licenses remain their authors'. No project license has been selected for this local review milestone. AI assistance supported implementation, tests, architecture review and documentation.

Public release is a later review step. The current repository and review archive are local, and no public GitHub remote or hosting deployment is configured.
